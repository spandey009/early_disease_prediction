# Early Disease Prediction — Educational ML Prototype

An educational machine learning project exploring binary health-risk classification using simulated health data. The project demonstrates data auditing, exploratory data analysis (EDA), preprocessing, model training, evaluation, and a Streamlit web application.

> **Important:** This project is for educational purposes only. It is not a clinically validated disease prediction system.

## Project Overview

The goal of this project is to demonstrate an end-to-end machine learning workflow using health-related features.

The workflow includes:
- Data auditing and quality checks
- Exploratory data analysis and visualization
- Data preprocessing and train-test splitting
- Training multiple classification models
- Evaluating and comparing model performance
- Interactive predictions through a Streamlit application

## Dataset and Limitations

The file `data/dataset.csv` contains **5,000 synthetic records generated for demonstration**. These are not real patient records and are not a downloaded PIMA Indians Diabetes, UCI Heart Disease, or BRFSS dataset.

The dataset includes these columns:

| Feature | Description |
|---|---|
| `patient_id` | Identifier assigned to a record |
| `age` | Age in years |
| `bmi` | Body mass index |
| `blood_pressure` | Illustrative blood pressure measurement |
| `glucose` | Illustrative glucose measurement |
| `cholesterol` | Illustrative cholesterol measurement |
| `smoking` | Binary smoking-status feature |
| `label` | Simulated binary target label |

The target label was generated using an illustrative noisy rule based on simulated features. Therefore, model performance measures how well the algorithms learn the simulated pattern. It does **not** demonstrate real-world medical accuracy or clinical usefulness.

For a research-quality extension, select one clearly defined disease and use an authentic, documented dataset with a compatible target. Synthetic data should remain separate from the real-data test set.

## Machine Learning Models

The project explores three classification algorithms:

1. **Logistic Regression** — a linear classification baseline.
2. **Random Forest** — an ensemble of decision trees.
3. **XGBoost** — a gradient-boosting algorithm.

The models are compared using classification metrics such as:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC, where applicable

Actual results are generated by the training and evaluation workflow and saved to `data/model_comparison.csv`. Results should be interpreted only in the context of the synthetic dataset.

## Installation and Setup

### 1. Clone the repository

```powershell
git clone YOUR_GITHUB_REPOSITORY_URL
cd "Early Disease Prediction"
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

### 2. Create and activate a virtual environment

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```
